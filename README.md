# Quanto Falta — França

Ligue 1 2026–27; 18 clubes e 34 jogos por clube.

Todos os dez módulos da base brasileira foram preservados. Dados desta liga, sem reaproveitar placares de outro país. A meta de pontos é editável; não representa probabilidade de permanência.

Atualização gratuita e manual: `python update.py`. Uma consulta Wikipedia e uma ESPN, sem Secret. Fonte comunitária conciliada; gols e datas só entram após conferência do placar. Recortes de 5/10 jogos ficam indisponíveis quando a temporada ainda não tem a amostra necessária. Calendário sem data é sinalizado. Comparação de técnicos usa marco escolhido pelo leitor. Mudanças da tabela são entre snapshots observados, sem atribuição causal a uma única partida.

GitHub Actions: publicar site ou atualizar dados. Sem cron. Arquivos JSON têm a mesma interface nas seis implantações, permitindo integração editorial.
